# Calculator Plugins C++

Учебный проект на C++: калькулятор с поддержкой подключаемых плагинов через динамические библиотеки.

## Возможности

- базовая архитектура калькулятора;
- подключение функций через отдельные DLL-плагины;
- загрузка плагинов во время выполнения программы;
- регистрация математических функций;
- обработка ошибок при вычислениях;
- модульная структура проекта.

## Реализованные плагины

- `FuncSin` — вычисление синуса;
- `FuncPow` — возведение в степень;
- `FuncLn` — вычисление натурального логарифма.

## Технологии

- C++
- ООП
- Dynamic libraries / DLL
- Visual Studio
- Windows API

## Структура проекта

- `Calculator/` — основное приложение калькулятора;
- `FuncSin/` — плагин функции синуса;
- `FuncPow/` — плагин возведения в степень;
- `FuncLn/` — плагин натурального логарифма;
- `CalculatorSolution.sln` — файл решения Visual Studio.

## Как запустить

1. Открыть `CalculatorSolution.sln` в Visual Studio.
2. Собрать решение.
3. Запустить основной проект `Calculator`.
4. Убедиться, что DLL-плагины собраны и доступны приложению.

## О проекте

Проект выполнен в рамках курса по C++.
Основной акцент сделан на модульную архитектуру, работу с динамическими библиотеками и расширяемость приложения через плагины.
